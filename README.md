# Factory Game

A 2D factory automation game for Windows: strip a dead world for the Galactic Federation.

**Download:** grab `FactoryGame-Setup.exe` from the [latest release](https://github.com/burtjames18-create/factory-game/releases/latest), or visit the download page.

The installer isn't code-signed, so Windows SmartScreen may warn you: click **More info → Run anyway**.

This repository holds the download website and the release builds.
